About Result Management System

The Student Result Management System is a web application developed using Python, Flask, HTML, CSS and SQLite.

Features

  • ✔ Admin Login
  • ✔ Add Student Result
  • ✔ Update Student Result
  • ✔ Delete Student Result
  • ✔ Search Student
  • ✔ Department Wise Result
  • ✔ Student Result Card
  • ✔ Automatic Grade Calculation
  • ✔ Pass / Fail Status

Technologies Used

Frontend HTML5, CSS3, Bootstrap
Backend Python Flask
Database SQLite
ORM Flask SQLAlchemy
